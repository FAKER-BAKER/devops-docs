# Эксплуатация

[Проверка отсутствующей страницы](missing-page.md)

После слияния в `main` откройте Actions → Publish documentation. Дождитесь завершения `build` и `deploy`, затем откройте URL окружения `github-pages`.

При отказе откройте журнал соответствующего шага и сверьтесь с [журналом инцидентов](incidents.md).

## Восстановление

Перед восстановлением изучите [журнал типовых инцидентов](incidents.md).
